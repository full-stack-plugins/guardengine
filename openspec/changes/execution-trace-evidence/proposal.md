# 真实测试执行、需求追踪与受信证据

用户要求多个智能体并行推进 TestGuard 的真实 Java/Maven 和 Cargo 测试执行、SpecGuard 需求到代码/测试追踪，以及 FlowGuard 的受信证据核验。本 change 是跨仓库唯一规格事实源，沿用原生业务规格和既有阶段治理。

新增显式授权执行器、当前源码/计划/产物绑定的执行回执、可选显式受信 Ed25519 签名、声明追踪图和只读证据门禁。已有导入报告保持未受信；无可信密钥或证据不足不能升级为通过；阶段与发布仍需真实审批。

不包含 OS 沙箱、不可伪造远程执行证明、自动业务审批、自动安装 Maven/JDK/Cargo 或自动修改项目策略。
