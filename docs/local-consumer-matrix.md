## Frozen capability gate

The machine-readable manifest and `tests/fixtures/consumer-corpus` are shipped together. Positive mapping is limited to the named producer commits, `guard.integration/v1alpha1`, and the explicit fixture/advisory profiles above. Negative mapping requires closed envelope fields and versions, exact raw artifact digests, exact report/envelope decision and coverage parity, and denial of a stronger capability than the producer supplies. A native exit code is command-specific: CodeGuard aggregate native 3 is not an approval decision; its current unqualified input projects to partial/BLOCK. Native runtime bytes remain separate from common artifacts.

A missing profile, unsupported producer version, incomplete observation, unverified authority, or unavailable current binding blocks the corresponding stronger consumer gate. Consumers must not infer qualified lint coverage, authentic approvals, Git source equivalence, hosted enforcement, or process containment from this corpus. No breaking decision is silently defaulted. The declared local protocol mapping has no unresolved field/version ambiguity; production qualification and external authority remain explicitly outside it.

GE owns schema validation, generic rule evaluation and artifact consistency. Each producer owns facts, capability declarations and its native command mapping. Controllers own current binding, authenticated authority, publication and side effects. The corpus imports no specialist source modules or domain policies into GE.
